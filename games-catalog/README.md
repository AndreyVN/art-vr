# Каталог игр ART-VR

Список игр клуба ART-VR для сайта — в том же формате, что каталог на vr-sky.ru. Сам сайт
art-vr.ru не менялся: здесь только данные, картинки и скрипты.

## Что в папке

- `games.json` — полный список игр клуба из таблицы «ART-VR», вкладка «Игры». У каждой игры
  есть `status`: в каталог попадают только `published`, у остальных статус — это причина
  (расшифровка — в разделе `statuses` того же файла).
- `images/games/*.jpg` — обложки 460×215 для карточек каталога.
- `images/games/covers/*.jpg` — обложки 600×750 для страницы игры на планшете и компьютере.
- `games-data.ts`, `games-summary.ts` — готовый каталог для сайта (только опубликованные игры,
  по убыванию популярности). Генерируются, руками их не правят.
- `scripts/sync-games.py` — обновление списка по таблице клуба.
- `scripts/generate-games.py` — сборка `games-data.ts` и загрузка недостающих обложек.
- Отчёт по каталогу (что опубликовано, что скрыто и почему, решения клуба) — `report.pdf` в корне
  проекта art-vr.

## Как читается таблица

- Основной список — игры на ПК. Красная заливка названия — не работает, «- пока нету» — не
  установлена, остальные работают.
- «Игры на шлемах» — работают на автономных шлемах; все однопользовательские, поэтому число
  игроков у них «1» (если игра есть и на ПК, берётся значение из основного списка).
- «Тестировали, но не понравились» — статус `rejected` («Не подошла клубу»), если в
  примечании «Не работает» — `broken`.
- «Игры на ПС» (PlayStation 5) и «Настольные игры» пока в каталог не входят — скрипт их
  пропускает.
- Из таблицы берутся игроки, возраст, время, жанр, зоны (`sheet_zones`), «Наш рейтинг»
  (`sheet_rating`), ссылка «Обзор» (`youtube`) и примечание (`sheet_note`).

Игры на шлемах опознаны по магазину Meta Quest (у одного названия в Steam и в магазине Meta
бывают разные игры).

## Обновление

Нужны Python 3 и пакеты `openpyxl`, `Pillow`.

```bash
python scripts/sync-games.py --dry-run                 # показать, что изменится
python scripts/sync-games.py                           # применить и пересобрать каталог
python scripts/sync-games.py --xlsx "путь к таблице.xlsx"
python scripts/generate-games.py --download            # докачать обложки
```

По умолчанию таблица берётся из `D:/projects/sites/ART-VR (2).xlsx`. Скрипт ничего не
удаляет: игру, пропавшую из таблицы, помечает `not_in_club`, новую строку добавляет
черновиком (`draft`) — допишите `description` и запустите синхронизацию ещё раз.

Поля, которые правятся вручную:

- `locked: true` — статус закреплён решением клуба, пояснение в `note`;
- `locked_fields` — проверенные значения (число игроков — источник в `players_source`,
  возраст): синхронизация их не перезаписывает и напоминает, если в таблице другое;
- `popularity` — порядок в каталоге (0–100, выше — раньше); основа расчёта — в
  `popularity_basis` (отзывы Steam, оценки магазина Meta, «Наш рейтинг» клуба);
- `image_source`, `cover_source` — откуда качать обложки (`cover_source: "blur"` — собрать
  вертикальную обложку из широкой на размытом фоне), `cover_focus` — что сохранить при
  обрезке по высоте (0 — верх, 1 — низ).

## Размещение на сайте

Сайт art-vr.ru сделан на том же Next.js, что и vr-sky.ru, поэтому каталог подключается так же:

1. `images/games` скопировать в `public/images/games`.
2. `games-data.ts` и `games-summary.ts` скопировать в `src/lib`.
3. Страницы и компоненты каталога взять из проекта vr-sky: `src/app/games`,
   `src/components/sections/games`, функция `plural` из `src/lib/utils.ts`, ссылки в
   `sitemap.ts` и в меню.
